Free, open-source Claude Code plugin

Claude Code reads whole files. Gio hands it the exact lines.

Gio is a plugin, not a proxy: a skill plus a few local Python scripts. It indexes your repo, turns each question into file:line spans, and tells Claude to read only those. Result on real repos: 6–14× fewer input tokens per task, same model, no API key, nothing leaves your machine.

How it works

Gio is a playbook Claude follows plus a few local Python scripts. No model calls of its own, no daemon, no account.

Locate before you read

A local index (BM25, optional on-device embeddings) turns “where is login handled” into exact file:line spans. Claude reads those lines, not the file.

Delegate the sweeps

Broad searches run in helper agents that return only the conclusion, so your main context stays small and every later turn is cheaper.

Keep the project sane

A DECISIONS.md log so choices aren’t re-argued, reuse-over-duplicate habits, and a six-phase review before anything merges.

Private by construction

Indexes live in your repo. The impact calculator reads the usage logs Claude Code already keeps on your disk. The only network access is an optional one-time embedding model download.

See what you saved

Ask “how much have I saved?” and Gio reports real spend from your logs plus an estimated saving versus a whole-file workflow, clearly labeled as an estimate.

When the index is wrong

Retrieval is a pointer, never the source of truth. Gio reads the span it found to confirm it before acting; if the code moved or the hit looks off, it falls back to grep and whole-file reads and rebuilds the index. You can override at any time by telling Claude to read the file. Gio is a playbook, not a gate.
