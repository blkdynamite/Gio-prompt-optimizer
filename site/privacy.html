Privacy

Last updated 2026-09-08. Plain language, not legal boilerplate.

The plugin

Gio runs on your machine. It reads your project files and the usage logs Claude Code already keeps under ~/.claude/. It sends nothing anywhere: no telemetry, no account, no analytics. The only optional network access is a one-time embedding model download if you install the semantic extras, and cloning two public repositories if you run the retrieval eval.

This website

The site is static and sets no cookies. Vercel, which hosts it, keeps standard request logs (IP address, user agent, time) for a short period as part of serving the page.

The notify-me form

  • What we collect: the email address you type, the time, and a keyed hash of your IP address used only to limit abuse. The raw IP address is not stored.
  • Why: to send you one message when the team tier ships. Nothing else.
  • Where: a database hosted by Supabase in the United States, reachable only by the site's own server function and the maintainer.
  • Sharing: none. The list is not sold, rented, or shared.
  • Removing your address: open an issue or discussion at github.com/blkdynamite/Gio-prompt-optimizer, or reply to the one email we send, and it will be deleted.
